CPU thread scheduling for Everwind on older CPUs

EverwindFXCore is a small DLL that loads with the game and changes how Windows hands out CPU time to Everwind's threads. It doesn't touch graphics settings, game files or saves. It is a port of my Windrose mod, WindroseFXCore, to Everwind (Unreal Engine 5.5).

Beta, and an honest one: the mod loads and tunes the game's threads as designed, but its effect on frame rate has not been measured in isolation yet. On my PC the big win came from two in-game settings, not from the DLL.

First: check these two settings

Measured on an FX-8350 with a Radeon RX 6600 at 1080p with a 60 FPS limit:

  • Frame Generation on: 30 real FPS (shown as 60), GPU 59%
  • Frame Generation off, native resolution: 55.6 average, dips to 47, GPU 91%
  • Frame Generation off, XeSS upscaling on Quality: 59.5 average, lowest 52, GPU 73%

Frame Generation with a 60 FPS limit renders only 30 real frames, because the limit applies to the displayed frames. On a 60 Hz display, turn it off. If your graphics card is near 100%, use XeSS upscaling on Quality. You don't need this mod for either of those.

What the mod changes

  • Exclusive game module (experimental, on by default). The GameThread, the busiest frame thread in Everwind, gets a whole AMD FX module or physical core to itself. Every other thread in the game is kept off it. Needs 8 or more logical processors.
  • Keeps the frame threads apart. The game, render and RHI threads each prefer their own core or module.
  • Keeps loading work out of the way. Asset streaming and decompression run on the other cores.
  • Protects the audio thread. The audio mixer gets its own preferred core and high priority.
  • Steadier frame pacing. 0.5 ms timer resolution, Above Normal priority for the frame threads, and no Windows power throttling for the game.
  • Optional audio buffer fix (off by default). Carried over from the Windrose mod; not needed or tested in Everwind on my PC.

Be realistic: at best it steadies frame times on CPUs where threads fight over shared cores. It won't help if your graphics card is the limit.

Install

  1. In Steam, right-click Everwind, then Manage, then Browse local files.
  2. Extract the zip into that folder. version.dll and EverwindFXCore.ini end up in skyverse\Binaries\Win64.
  3. Start the game. An EverwindFXCore.log appears next to the DLL and shows your CPU and the threads it adjusted. No log means it didn't load.

Every fix has its own switch in EverwindFXCore.ini, so you can turn things off one at a time and compare.

Uninstall

If you turned on the audio buffer fix, set AudioBufferFix=0 and start the game once. Then delete version.dll, EverwindFXCore.ini, EverwindFXCore.log and EverwindFXCore.state from skyverse\Binaries\Win64.

Good to know

  • Everwind had no anti-cheat in its install folder when this was released (November 2026). If that changes, remove the DLL before playing online.
  • It conflicts with any other mod that also loads through version.dll.
  • Please post your CPU, GPU and log in the comments, with FPS for Enabled=1 and Enabled=0 in the same spot.
